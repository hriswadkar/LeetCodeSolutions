# LeetCode Solutions

Solutions to [LeetCode](https://leetcode.com/) challenges implemented in **C#, Java, and Python**.

The purpose of this repository is to practice problem solving and improve my understanding of algorithms and data structures while implementing solutions in different programming languages.

## Languages

| Language | Solutions          |
| -------- | ------------------ |
| C#       | [CSharp](./CSharp) |
| Java     | [Java](./Java)     |
| Python   | [Python](./Python) |


## Problems

Problems are solved in different languages rather than necessarily using the same language for every challenge. This is intentional and provides an opportunity to practice the same problem-solving concepts across C#, Java, and Python.

## Goal

* Practice LeetCode challenges regularly
* Improve problem-solving and algorithmic thinking
* Strengthen knowledge of data structures and algorithms
* Gain practical experience with C#, Java, and Python
* Compare different approaches and language features
